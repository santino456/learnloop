# Answer

你观察到的“空链接”是因为链接被重定向到了不存在的页面。

在原始 Markdown 里，这两篇延伸阅读写的是：

- [Accelerating Large Language Model Decoding with Speculative Sampling](https://arxiv.org/abs/2302.01318)
- [Fast Inference from Transformers via Speculative Decoding](https://arxiv.org/abs/2211.17192)

但 LearnLoop 的构建流程会把 `arxiv.org/abs/<id>` 自动改写成 `arxiv.org/html/<id>`，目的是直接打开论文的 HTML 阅读页。问题是：这两篇论文比较老（2022、2023），arXiv 并没有为它们生成 HTML 版本，`https://arxiv.org/html/2302.01318` 会返回 404，所以你在浏览器里看到的就是“空页面”或“链接失效”。

## 已修复

我已经修改了 `learnloop/parser.py` 里的 arXiv 链接重写逻辑：

- 如果原文没有指定章节/附录锚点，就保留原来的 `arxiv.org/abs/<id>` 链接；
- 只有在明确写了 `§xx` 或 `Appendix X` 锚点时，才改写成 `arxiv.org/html/<id>#anchor`。

`arxiv.org/abs/<id>` 是 arXiv 的摘要页，对所有论文都可用，并且页面上有 PDF 下载入口，不会再出现 404。

## 验证

已重新构建课程：

```bash
learnloop validate courses/model/dspark
learnloop build courses/model/dspark
learnloop audit courses/model/dspark
```

现在 `dist/m1.html` 里的两个链接已经指向：

- `https://arxiv.org/abs/2302.01318`
- `https://arxiv.org/abs/2211.17192`

刷新 `http://127.0.0.1:8787/course/dspark/m1.html` 即可正常访问。

## Course Update Recommendation

这次问题暴露的是一个构建工具层面的 bug，而不是课程内容本身的错误。修复已经在 `learnloop/parser.py` 中完成，所有课程都会受益。DSpark 课程的 Markdown 源不需要改动。

如果以后引用 arXiv 论文时想要链接到 HTML 版本，可以确认该论文是否有 HTML 版（较新的论文，如 2025 年以后的基本都有）；对于老论文，建议继续使用 `/abs/` 链接。
