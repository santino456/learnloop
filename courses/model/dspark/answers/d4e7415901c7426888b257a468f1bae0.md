# Answer

用户针对的是这句话：

> 如果拒绝，从 $(q(x) - p(x))_+$ 中重采样。

问：为什么从这个分布重采样？采样完然后呢？

## 1. 为什么从 $(q - p)_+$ 重采样？

Speculative Sampling 的目标是从目标分布 $q$ 采样，但先用 draft 分布 $p$ 采样一个候选 $\tilde{x}$，然后以概率 $\min(1, q(\tilde{x})/p(\tilde{x}))$ 接受。

如果候选 $\tilde{x}$ 被拒绝，说明 $p$ 在这个 token 上“过度自信”了——$p$ 给它的概率比 $q$ 给的更高。我们不能直接从 $q$ 重采样，因为那样会重复计算已经被 $p$ 尝试过的概率质量。正确的做法是从“$q$ 比 $p$ 多出来的部分”中采样：

$$
(q(x) - p(x))_+ = \max(0, q(x) - p(x))
$$

这个分布只包含 $q$ 比 $p$ 更看好的 token，避开了 $p$ 已经高估过的区域。

## 2. 采样完然后呢？

这一轮结束，输出的就是这次重采样的 token。然后下一轮再用新的上下文重新生成 $\gamma$ 个候选。

注意：Speculative Sampling 的算法不是“拒绝一个、修正一个、再继续验证原来剩下的候选”，而是**一旦拒绝，本轮就只输出那个修正 token，然后重新开始下一轮**。所以每轮最多接受 $\gamma$ 个候选 + 1 个修正/bonus token。

## 3. 直观例子

假设词表里只有 A、B、C 三个 token：

| token | $q$（目标） | $p$（draft） |
|---|---|---|
| A | 0.5 | 0.3 |
| B | 0.3 | 0.5 |
| C | 0.2 | 0.2 |

如果 draft 采样出 B：
- 接受概率 = $\min(1, 0.3/0.5) = 0.6$。
- 如果拒绝，从 $(q - p)_+$ 重采样。
- 这时 $(q-p)_+ = \{\text{A}: 0.2, \text{B}: 0, \text{C}: 0\}$，归一化后只可能采样 A。

可以看到，B 被拒绝后不会再选 B，而是从 A 采样——这正是修正采样的意义。
