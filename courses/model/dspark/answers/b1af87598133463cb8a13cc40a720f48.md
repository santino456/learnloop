# Answer

用户针对的是 Speculative Decoding 的 Algorithm 1，问题集中在接收条件和 bonus / 修正 token。

## 1. 为什么接收条件是 $r_i > p_i(x_i)/q_i(x_i)$？

这是**拒绝采样**的标准技巧。我们想从目标分布 $p$ 采样，但直接采样 $p$ 很贵。于是先从便宜的近似分布 $q$ 采样一个候选 $x_i$，再用一个均匀随机数 $r_i \sim U(0,1)$ 决定是否接受：

- 如果 $r_i \le p_i(x_i)/q_i(x_i)$，接受 $x_i$。
- 如果 $r_i > p_i(x_i)/q_i(x_i)$，拒绝 $x_i$，并停止继续检查后面的候选。

可以验证：被接受的 token 的条件分布恰好是 $p_i$。拒绝概率是 $1 - p_i(x_i)/q_i(x_i)$。

注意：$p_i(x_i)/q_i(x_i)$ 可以大于 1，但概率最大是 1，所以接受概率是 $\min(1, p_i/q_i)$。算法里用 $r_i > p_i/q_i$ 作为拒绝条件，等价于接受概率是 $\min(1, p_i/q_i)$。

## 2. 为什么找到第一个拒绝的位置 $n+1$ 就停？

因为候选序列 $x_1, \dots, x_\gamma$ 是**按顺序依赖生成的**：$x_i$ 的输入里包含 $x_{i-1}$。如果 $x_{n+1}$ 被拒绝，说明它不能作为目标分布的有效样本；那么基于它继续生成的 $x_{n+2}, \dots$ 也没有意义了。所以只能保留前 $n$ 个接受的 token。

## 3. Bonus token 和修正 token 的区别

- **全部接受（$n = \gamma$）**：
  前 $\gamma$ 个候选都 ok。但我们已经让目标模型多算了一个位置 $\gamma+1$ 的分布 $p_{\gamma+1}$，所以可以直接从 $p_{\gamma+1}$ 再采样 1 个 token，作为“奖励”。这一轮总共产出 $\gamma + 1$ 个 token。

- **提前拒绝（$n < \gamma$）**：
  前 $n$ 个 ok，第 $n+1$ 个不 ok。我们需要从位置 $n+1$ 重新采样一个 token，但这个 token 必须满足：
  - 目标分布是 $p_{n+1}$；
  - 我们已经知道 $q_{n+1}$ 给出的候选被拒绝了。
  修正分布就是 $\text{norm}(\max(0, p_{n+1} - q_{n+1}))$。它把 $q$ 已经“预支”掉的概率质量补回来，保证最终仍然服从 $p_{n+1}$。

## 4. 为什么每轮至少产 1 个 token？

即使第一个候选就被拒绝（$n=0$），我们仍然会从修正分布 $\text{norm}(\max(0, p_1 - q_1))$ 中采样一个 token，作为本轮输出。所以永远不会比自回归慢。
